# YumeCraft

YumeCraft is a Minecraft plugin that adds psychedelic effects to the game, including visual distortions, color shifts, and sound enhancements. It transforms the player's experience with vibrant, constantly changing colors, dynamic UI elements, and immersive sound effects, creating a unique and immersive gameplay environment.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Join the Minecraft server where the plugin is installed.
2. Use the command `/psychedelic` to toggle the psychedelic effects on or off.
3. Enjoy the enhanced visual and auditory experience.
